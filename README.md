Saw that there wasn't a Help Wanted 2 Archipelago, so decided to make one

* Faz Force Ending: Collect 6 Faz Force Toys to Goal
* Princess Quest 4 Ending: Collect 6 Memory Dolls to Goal
* M.X.E.S. Ending: Collect 12 Puzzle Peices to Goal
